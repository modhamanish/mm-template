# 🚀 Introduction to MMTemplate

**MMTemplate** is an enterprise-grade, highly modular **React Native boilerplate** built with **TypeScript**, **React 19**, and **React Native 0.87+**.

It is crafted to jumpstart your mobile application development with industry best practices, modern clean architecture, scalable state management, and an **Interactive CLI Setup Wizard**.

## 🌟 Why MMTemplate?

Starting a fresh React Native project often requires days of boilerplate setup: configuring navigation, theming, localization, authentication guards, API interceptors, responsive scaling, and linting rules. 

**MMTemplate solves this once and for all:**

- 🪄 **Interactive CLI Wizard**: Answer 3 quick terminal questions during initialization to auto-configure Onboarding, Auth, and Navigation architecture.
- 🧱 **Clean & Feature-Driven Architecture**: Clear separation of concerns between UI components, screens, navigation stacks, services, context, and utilities.
- 🧭 **React Navigation 7 Pre-configured**: Seamless support for Native Stack, Bottom Tabs, and Drawer navigation with fluid 60fps animations.
- ⚡ **TanStack Query (React Query v5)**: Server-state synchronization, query caching, background refetching, and clean mutation hooks.
- 🌐 **Multi-Language (i18n)**: Out-of-the-box internationalization supporting English and Hindi with dynamic language switching.
- 🎨 **Unified Design System & Theming**: Light/Dark theme engine with automatic OS preference detection and persistent user choice.
- 🛡️ **End-to-End TypeScript**: Strict type safety across navigation routes, components, API responses, and theme tokens.

## ⚡ Quick Start

Initialize your new app with a single command:

```bash
npx @react-native-community/cli@latest init MyApp --template @modhamanish/rn-mm-template
```

> 💡 *Replace `MyApp` with your desired application name.*

Next, proceed to the [Installation Guide](./getting-started/installation) to set up your environment and dependencies.
